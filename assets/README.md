# Snodo brand assets

Production-oriented vector reconstruction of the approved Snodo logo concept for the Elixir MCP library. Source was a generated raster image, so these are newly authored SVG paths, not the original image generator's vector data.

## Recommended GitHub usage

Place `svg/snodo-lockup-color.svg` in `assets/snodo-logo.svg` and add to your repository README:

```markdown
<p align="center"><img src="assets/snodo-logo.svg" alt="Snodo" width="440"></p>
```

Use `svg/snodo-icon-color.svg` for a standalone mark, or `png/snodo-lockup-color-256h.png` where SVG is not supported. SVGs have transparent backgrounds. White variants are intended for dark backgrounds.

## Palette

- Lagoon blue: `#083855` (RGB 8, 56, 85)
- Venetian orange: `#D55725` (RGB 213, 87, 37)
- Black: `#000000`; white: `#FFFFFF`

## Typography

The lowercase wordmark was constructed from **Comfortaa Bold** (SIL Open Font License 1.1), then converted to outlined vector glyphs. No fonts are needed to display the exported SVGs. This is a close production reconstruction, not a claim to recover the exact typeface from the generated reference.

## Files

- `svg/snodo-icon-{color,black,white}.svg`
- `svg/snodo-lockup-{color,black,white}.svg`
- `png/` transparent icon PNGs at 64, 128, 256, 512 and 1024 px, plus lockup PNGs at 128, 256 and 512 px high

All SVGs use one shared icon geometry. No background, gradients, shadows or embedded raster imagery.
